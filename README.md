# Movie-Recommendation
"基于预训练语言模型的语义匹配与多目标优化的内容感知推荐系统"
算法逻辑举例
用户说："犯罪片，要紧张刺激的"
↓ 系统理解：
- 题材：犯罪 ✓
- 风格：紧张、刺激
- 情感：惊险、悬疑
2. 把文字变成数字（核心）
text
"紧张刺激" → [0.12, -0.05, 0.34, 0.21, ...] (384个数字)

每部电影的(标语+简介)也变成这样的数字串
《无间道》："卧底、黑帮" → [0.15, -0.03, 0.32, 0.18, ...]
《盗梦空间》："梦境、冒险" → [0.08, 0.02, 0.25, 0.15, ...]
3. 计算匹配度
text
比较"紧张刺激"和每部电影的数字串：
- 《无间道》：相似度 0.85（很像！）
- 《盗梦空间》：相似度 0.65（有点像）
- 《泰坦尼克号》：相似度 0.15（完全不像）
4. 结合电影评分
text
最终分数 = 文本匹配度 × 60% + 评分 × 40%

举例：
《无间道》：文本0.85 + 评分9.3 = 综合0.89
《肖申克的救赎》：文本0.60 + 评分9.7 = 综合0.82
→ 推荐《无间道》（更符合"紧张刺激"）
